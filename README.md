# Portafolio Web Juan José Rangel

En este repositorio podrás encontrar mi portafolio web, este se encuentra dividido en varios archivos que permiten su funcionamiento, este portafolio web tiene de objetivo ofrecer una manera más cómoda comodidad de presentar mi hoja de vida.



### Estructura

Este repositorio contiene 4 archivos los cuáles permiten el correcto funcionamiento del portafolio web, los archivos son index.html que contiene la estructura de la página, styles.css que se encarga de todo lo visual, Foto hoja de vida que permite ver mi foto en la página y finalmente el archivo PDF Hoja de Vida Juan Rangel.



### Funcionamiento

Para un correcto funcionamiento del portafolio web es necesario descargar el repositorio, posteriormente se tendrá una carpeta comprimida como .zip, es vital descomprimirla para luego abrir la carpeta y allí abrir el archivo llamado index.
